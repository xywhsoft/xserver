xs.json 数据结构可以是一张表，或者一个数组

如果是一张表，XS 只会启动一个服务，如果是一个数组，数组内的每个元素都应该是这样的表，XS 会启动多个服务

下面是这张表的字段和含义：

	enabled							是否启用服务
	class							服务类型
		可选值：
			http					启动HTTP服务
			mqtt					启动MQTT服务
			custom					启动自定义服务（通过对应编程语言的回调函数决定功能）
			thread					启动一条线程运行服务（通过对应编程语言的回调函数决定功能）
	name							服务名称
	desc							服务描述
	param							服务器启动参数（XS 不会主动使用这个字段，供二次开发用）
	addr							服务绑定的地址和端口（custom 和 thread 类型时，XS 不会主动使用这个字段）
	tls								是否启用 TLS 1.3 加密传输（custom 和 thread 类型时，XS 不会主动使用这个字段）
	addr_tls						加密传输的地址和端口（custom 和 thread 类型时，XS 不会主动使用这个字段）
	host_default					服务默认 host（理解为一个服务绑定多个域名，找不到对应 host 就使用这个）
	hosts							host 列表

一个服务可以通过 host（绑定域名）服务多个虚拟主机，host 也是一张表，这张表的字段和含义：

	enabled							是否启用主机
	name							主机名称
	desc							主机描述
	host							主机绑定域名，多个域名可使用 ; 分开
	wwwroot							主机根目录，可以填写相对路径或绝对路径（linux不以/开头的就是相对路径，windows不含:的就是相对路径），相对路径会以 XS 程序所在目录为参照
	tls_ca							TLS 1.3 CA 证书文件路径
	tls_cert						TLS 1.3 Cert 证书文件路径
	tls_key							TLS 1.3 秘钥文件路径
	devlang							主机开发使用的编程语言
		可选值：
			static					静态页面（默认值）
			c						使用 C 语言进行开发
			lua						使用 lua 进行开发（暂不支持）
			js						使用 JavaScript 进行开发（暂不支持）
	devfile							主机开发回调的入口文件（devlang=static 时无效）
		回调函数：
			ServiceInit				服务启动前调用（仅默认主机支持这个字段；函数不存在则不会调用）
			ServiceStart			服务启动（仅默认主机支持这个字段；HTTP、MQTT等内置逻辑的服务不会调用此函数，自定义服务函数不存在则不会调用）
			ServiceUnit				服务启动后调用（仅默认主机支持这个字段；函数不存在则不会调用）
			RequestProc				HTTP 请求回调（函数不存在则不会调用）
