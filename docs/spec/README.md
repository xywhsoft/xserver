# XServer 文档 Spec

这个目录只存放文档规划，不存放正式文档内容。

当前目标：

- 先定义新的文档分类结构
- 先列出首批应该编写的文档
- 先标记每个文件的优先级、状态、来源依据
- 先固定文件命名和中英文双份策略
- 正式文档后续再按本 spec 落地

当前结论：

- 现有代码已经足够支撑“第一阶段现状文档”
- 现有代码还不适合直接写成“全部语义已最终定稿”的文档
- `force / draining`、显式生命周期状态机、旧文档迁移统一，仍需在正式文档中谨慎表述
- 对外文档统一只使用 `XServer` 这个名字，不使用内部代号作为产品名
- 正式文档文件名统一使用英文命名
- 每篇正式文档固定保留中英文两份：`xxx.md` 为中文，`xxx.en.md` 为英文
- 当前阶段只先编写中文版本，英文版本在中文审阅通过后再翻译

建议先读：

- [目录结构规划](./structure.md)
- [编写约定](./conventions.md)
- [进度追踪](./progress.md)

现有 `docs` 根目录中的文件暂时视为“旧版文档 / 设计草案”：

- `docs/配置说明.md`
- `docs/服务类型.md`
- `docs/热加载.md`
- 现有设计草案文件

后续正式整理时，建议按新目录逐步拆分、迁移、归档，而不是继续在旧文件上叠加内容。
