# XServer 服务热加载

XServer 支持在运行时热加载 TCC 脚本，无需重启服务即可更新代码逻辑。

## 函数列表

### xsReloadHost

通过对象热加载指定 Host 的脚本。

```c
int xsReloadHost(XS_ServerObject objServer, XS_HostObject objHost);
```

**参数：**
- `objServer` - 服务器对象
- `objHost` - Host 对象

**返回值：** `0` 表示成功，负数表示失败

**示例：**
```c
// 在 EventProc 或 RequestProc 回调中使用
int RequestProc(XS_ServerObject objServer, XS_HostObject objHost, struct mg_connection* c, struct mg_http_message* hm)
{
    // 热加载当前 Host
    int ret = xsReloadHost(objServer, objHost);
    if ( ret == 0 ) {
        printf("热加载成功\n");
    }
    return 1;
}
```

---

### xsReloadHostByDomain

通过域名热加载 Host 的脚本。

```c
int xsReloadHostByDomain(XS_ServerObject objServer, const char* sDomain);
```

**参数：**
- `objServer` - 服务器对象
- `sDomain` - 域名（xs.json 中 host 字段配置的值）

**返回值：** `0` 表示成功，负数表示失败

**示例：**
```c
// 热加载 example.com 域名对应的 Host
int ret = xsReloadHostByDomain(objServer, "example.com");
```

---

### xsReloadDefaultHost

热加载 DefaultHost 的脚本。

```c
int xsReloadDefaultHost(XS_ServerObject objServer);
```

**参数：**
- `objServer` - 服务器对象

**返回值：** `0` 表示成功，负数表示失败

**示例：**
```c
// 热加载默认主机
int ret = xsReloadDefaultHost(objServer);
```

---

### xsReloadServer

热加载整个 Server 的所有 Host（包括 DefaultHost 和 hosts 列表中的所有 Host）。

```c
int xsReloadServer(XS_ServerObject objServer);
```

**参数：**
- `objServer` - 服务器对象

**返回值：** 成功加载的 Host 数量，负数表示参数错误

**示例：**
```c
// 热加载整个服务器的所有 Host
int count = xsReloadServer(objServer);
printf("成功热加载 %d 个 Host\n", count);
```

## 错误码

| 错误码 | 含义 |
|--------|------|
| `0` | 成功 |
| `-1` | 非 C 语言脚本（devlang 不是 "c"） |
| `-2` | 脚本文件不存在 |
| `-3` | TCC 状态机创建失败 |
| `-4` | 脚本编译失败 |
| `-5` | 地址重定位失败 |
| `-100` | 参数无效（传入 NULL） |
| `-101` | 域名未找到（HostMap 中不存在） |
| `-102` | DefaultHost 未启用 |

## 热加载流程

热加载时会按以下顺序执行：

1. **调用 `ServiceUnit`** - 调用旧脚本的 `ServiceUnit` 函数（如果存在），用于清理旧脚本持有的资源
2. **销毁旧 TCC 状态机** - 释放旧脚本占用的内存
3. **创建新 TCC 状态机** - 初始化新的编译环境
4. **编译新脚本** - 读取并编译脚本文件
5. **传递全局数据** - 调用 `XS_SetGlobalDate` 传递 mgr、ServerList 等全局数据
6. **调用 `ServiceInit`** - 调用新脚本的 `ServiceInit` 函数（如果存在），用于初始化新脚本

---

## 注意事项

1. **仅支持 C 语言脚本** - 只有 `devlang` 配置为 `"c"` 的 Host 才能热加载
2. **资源清理** - 请在 `ServiceUnit` 函数中正确释放所有资源，避免内存泄漏
3. **线程安全** - 热加载过程中，正在处理的请求可能会使用旧的回调函数，新请求会使用新的回调函数
4. **编译错误** - 如果新脚本编译失败，旧脚本已被销毁，该 Host 将无法处理请求，请确保脚本无语法错误后再热加载

## 典型应用场景

### 1. 开发调试

在开发阶段，修改脚本后通过 HTTP 接口触发热加载，无需重启服务：

```c
int RequestProc(XS_ServerObject objServer, XS_HostObject objHost, struct mg_connection* c, struct mg_http_message* hm)
{
    if ( mg_match(hm->uri, mg_str("/_reload"), NULL) ) {
        int ret = xsReloadHost(objServer, objHost);
        char sBody[64];
        sprintf(sBody, "{\"code\":%d}", ret);
        http_reply(c, 200, "Content-Type: application/json\r\n", sBody, 0);
        return 1;
    }
    // ... 其他请求处理 ...
    return 0;
}
```

### 2. 配置热更新

通过管理接口热加载指定域名的配置：

```c
// 根据请求参数热加载指定域名
char sDomain[256];
mg_http_get_var(&hm->query, "domain", sDomain, sizeof(sDomain));
int ret = xsReloadHostByDomain(objServer, sDomain);
```

### 3. 批量更新

一次性热加载整个服务器的所有 Host：

```c
int count = xsReloadServer(objServer);
printf("批量热加载完成，成功 %d 个\n", count);
```
