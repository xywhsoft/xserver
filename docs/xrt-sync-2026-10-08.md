## 接入方式

- 扩展改用上游 `include`、`src`、`config` 目录与模块清单。原生 C 文件分开编译，不拼接为单一实现文件。
- `tools/extensions.json` 从模块清单生成，保留公开头和既有扩展依赖，显式选择各模块 feature。邮件共享传输实现等独立翻译单元因此与产品实现采用一致的开关。
- TCC 使用同一批公开头、声明导入和功能开关。`xrt/detail/wait.h` 是上游真实辅助实现，原生编译和递归 SDK 打包都会包含它。
- `xllm-executor.h` 在 TCC 虚拟文件系统中保留为公开 `xllm/executor.h` 的入口别名。
- 同步器更新前检查旧快照，旧快照拥有的过期文件才会被清理；本地 vendor 改动会报错，不能被静默覆盖。生成文件采用 LF，避免 Windows 换行转换破坏哈希。

本次还适配 xs 自身的时间契约：等待 API 使用有符号毫秒；HTTP/TCP/WebSocket 定时器不再乘一千；空闲时间使用新的毫秒时钟；ACME 条件等待保留单调截止预算，正确处理重复唤醒、停止和错误。业务暴露的定时器仍以毫秒计。
