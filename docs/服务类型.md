# XServer 服务类型指南

XServer 支持 8 种服务类型，本文档介绍每种服务的特点、使用方式和最佳实践。

---

## 服务类型概览

| 服务类型 | class 值 | 协议 | TLS 支持 | 适用场景 |
|----------|----------|------|----------|----------|
| HTTP | `http` | HTTP/1.1 | HTTPS | Web 服务、REST API |
| MQTT | `mqtt` | MQTT 3.1.1 | MQTTS | IoT 消息推送、设备通信 |
| WebSocket | `ws` | WebSocket | WSS | 实时通信、长连接 |
| XTP | `xtp` | XTP（自定义） | XTPS | 高性能二进制通信 |
| TCP | `tcp` | 原始 TCP | - | 自定义协议开发 |
| UDP | `udp` | UDP | - | 低延迟通信、广播 |
| Custom | `custom` | 自定义 | - | 事件驱动的自定义服务 |
| Thread | `thread` | - | - | 独立线程任务 |

---

## HTTP 服务

HTTP 服务是最常用的 Web 服务类型，支持静态文件服务和动态请求处理。

### 配置示例

```json
{
    "enabled": true,
    "class": "http",
    "name": "Web Server",
    "addr": "http://0.0.0.0:80",
    "tls": true,
    "addr_tls": "https://0.0.0.0:443",
    "host_default": {
        "enabled": true,
        "path": "wwwroot",
        "tls_cert": "tls/cert.pem",
        "tls_key": "tls/key.pem",
        "devlang": "c",
        "devfile": "script/main.c"
    },
    "hosts": []
}
```

### 回调函数

```c
// HTTP 请求处理
int RequestProc(XS_ServerObject objServer, XS_HostObject objHost, 
                struct mg_connection* c, struct mg_http_message* hm)
{
    // 获取请求方法和路径
    printf("Method: %.*s\n", (int)hm->method.len, hm->method.buf);
    printf("URI: %.*s\n", (int)hm->uri.len, hm->uri.buf);
    
    // 路由处理
    if ( mg_match(hm->uri, mg_str("/api/hello"), NULL) ) {
        mg_http_reply(c, 200, "Content-Type: application/json\r\n", 
                      "{\"message\":\"Hello World\"}");
        return 1;  // 已处理
    }
    
    return 0;  // 未处理，继续默认处理（静态文件服务）
}
```

### 最佳实践

1. **虚拟主机** - 使用 `hosts` 数组配置多个域名，每个域名可以有独立的证书和脚本
2. **静态文件** - 将 `devlang` 设为 `static` 可直接提供静态文件服务
3. **SNI 支持** - HTTPS 支持 SNI，不同域名可使用不同证书
4. **调试模式** - 开启 `debug: true` 可在控制台查看请求日志

### 常用事件

| 事件 | 说明 |
|------|------|
| `MG_EV_HTTP_MSG` | 收到完整 HTTP 请求 |
| `MG_EV_HTTP_CHUNK` | 收到 HTTP 分块数据 |
| `MG_EV_ACCEPT` | 新连接建立 |
| `MG_EV_CLOSE` | 连接关闭 |

## MQTT 服务

MQTT 是轻量级的消息传输协议，适用于 IoT 场景。

### 配置示例

```json
{
    "enabled": true,
    "class": "mqtt",
    "name": "MQTT Broker",
    "addr": "mqtt://0.0.0.0:1883",
    "tls": true,
    "addr_tls": "mqtts://0.0.0.0:8883",
    "host_default": {
        "enabled": true,
        "path": "mqtt",
        "tls_cert": "tls/cert.pem",
        "tls_key": "tls/key.pem",
        "devlang": "c",
        "devfile": "mqtt/main.c"
    },
    "hosts": []
}
```

### 回调函数

```c
// MQTT 事件处理
int EventProc(XS_ServerObject objServer, XS_HostObject objHost,
              struct mg_connection* c, int ev, void* ev_data)
{
    if ( ev == MG_EV_MQTT_CMD ) {
        struct mg_mqtt_message* mm = (struct mg_mqtt_message*)ev_data;
        
        if ( mm->cmd == MQTT_CMD_PUBLISH ) {
            printf("Topic: %.*s\n", (int)mm->topic.len, mm->topic.buf);
            printf("Data: %.*s\n", (int)mm->data.len, mm->data.buf);
            // 自定义消息处理...
        }
    }
    return 0;  // 继续默认处理（消息转发）
}
```

### 最佳实践

1. **QoS 支持** - 内置支持 QoS 0/1，适合大多数场景
2. **主题通配符** - 支持 `+`（单级）和 `#`（多级）通配符
3. **客户端认证** - 可在 `EventProc` 中处理 `MQTT_CMD_CONNECT` 实现认证
4. **消息持久化** - 如需消息持久化，可在回调中保存到数据库

### MQTT 命令类型

| 命令 | 说明 |
|------|------|
| `MQTT_CMD_CONNECT` | 客户端连接 |
| `MQTT_CMD_SUBSCRIBE` | 订阅主题 |
| `MQTT_CMD_UNSUBSCRIBE` | 取消订阅 |
| `MQTT_CMD_PUBLISH` | 发布消息 |
| `MQTT_CMD_PINGREQ` | 心跳请求 |
| `MQTT_CMD_DISCONNECT` | 断开连接 |

## WebSocket 服务

WebSocket 提供全双工通信，适用于实时应用。

### 配置示例

```json
{
    "enabled": true,
    "class": "ws",
    "name": "WebSocket Server",
    "addr": "ws://0.0.0.0:8080",
    "tls": true,
    "addr_tls": "wss://0.0.0.0:8443",
    "host_default": {
        "enabled": true,
        "path": "ws",
        "tls_cert": "tls/cert.pem",
        "tls_key": "tls/key.pem",
        "devlang": "c",
        "devfile": "ws/main.c"
    },
    "hosts": []
}
```

### 回调函数

```c
int EventProc(XS_ServerObject objServer, XS_HostObject objHost,
              struct mg_connection* c, int ev, void* ev_data)
{
    if ( ev == MG_EV_HTTP_MSG ) {
        struct mg_http_message* hm = (struct mg_http_message*)ev_data;
        // 自定义升级路径
        if ( mg_match(hm->uri, mg_str("/chat"), NULL) ) {
            mg_ws_upgrade(c, hm, NULL);
            return 1;
        }
    } else if ( ev == MG_EV_WS_OPEN ) {
        // WebSocket 连接建立
        printf("WebSocket connected\n");
    } else if ( ev == MG_EV_WS_MSG ) {
        // 收到 WebSocket 消息
        struct mg_ws_message* wm = (struct mg_ws_message*)ev_data;
        printf("Received: %.*s\n", (int)wm->data.len, wm->data.buf);
        
        // 回复消息
        mg_ws_send(c, wm->data.buf, wm->data.len, WEBSOCKET_OP_TEXT);
        return 1;
    }
    return 0;
}
```

### 最佳实践

1. **消息类型** - 使用 `WEBSOCKET_OP_TEXT` 发送文本，`WEBSOCKET_OP_BINARY` 发送二进制
2. **广播消息** - 遍历连接列表向所有客户端发送消息
3. **心跳检测** - 客户端应定期发送 ping 保持连接
4. **分片处理** - 大消息会自动分片，使用 `MG_EV_WS_CTL` 处理控制帧

### WebSocket 事件

| 事件 | 说明 |
|------|------|
| `MG_EV_WS_OPEN` | WebSocket 握手完成 |
| `MG_EV_WS_MSG` | 收到 WebSocket 消息 |
| `MG_EV_WS_CTL` | 收到控制帧（ping/pong/close） |

## XTP 服务

XTP 是 XServer 自定义的轻量级二进制协议，适用于高性能场景。

### 协议格式

```
+------------------+-------------------+-------+---------+------+
| Header (16B)     | ParamInfo (4B*n)  | Cmd   | Params  | Body |
+------------------+-------------------+-------+---------+------+
```

**Header 结构 (16 字节)：**
- `HeadInfo[4]` - 包头标识 "xtp\1"
- `PackSize` - 包总长度
- `CmdSize` - 命令长度
- `ParamCount` - 参数数量
- `BodySize` - Body 长度

### 配置示例

```json
{
    "enabled": true,
    "class": "xtp",
    "name": "XTP Server",
    "addr": "tcp://0.0.0.0:9000",
    "tls": true,
    "addr_tls": "tcp://0.0.0.0:9443",
    "host_default": {
        "enabled": true,
        "path": "xtp",
        "devlang": "c",
        "devfile": "xtp/main.c"
    },
    "hosts": []
}
```

### 回调函数

```c
int EventProc(XS_ServerObject objServer, XS_HostObject objHost,
              struct mg_connection* c, int ev, void* ev_data)
{
    if ( ev == MG_EV_READ ) {
        // XTP 消息已解析，ev_data 为 XTP_MessageObject
        XTP_MessageObject msg = (XTP_MessageObject)ev_data;
        
        printf("Command: %s\n", msg->Cmd);
        printf("Body: %s\n", msg->Body);
        
        // 获取参数
        char* sUser = XTP_GetParam(msg, "user");
        if ( sUser ) {
            printf("User: %s\n", sUser);
        }
        
        // 发送响应
        str arrParam[] = {"status"};
        str arrValue[] = {"ok"};
        XTP_Send(c, "response", 0, 1, arrParam, arrValue, "success", 0);
        
        return 1;
    }
    return 0;
}
```

### API 函数

```c
// 发送 XTP 消息
int XTP_Send(struct mg_connection* c, str sCmd, size_t iCmdSize,
             uint iParamCount, str* arrParam, str* arrValue,
             ptr pBody, size_t iBodySize);

// 获取消息参数
char* XTP_GetParam(void* msg, const char* sKey);
```

### 最佳实践

1. **命令路由** - 使用 `msg->Cmd` 做命令分发
2. **参数传递** - 使用参数字典传递键值对数据
3. **二进制数据** - Body 支持任意二进制数据
4. **连接复用** - XTP 基于 TCP，支持连接复用

## TCP 服务

原始 TCP 服务，适用于自定义协议开发。

### 配置示例

```json
{
    "enabled": true,
    "class": "tcp",
    "name": "TCP Server",
    "addr": "tcp://0.0.0.0:5000",
    "host_default": {
        "enabled": true,
        "path": "tcp",
        "devlang": "c",
        "devfile": "tcp/main.c"
    },
    "hosts": []
}
```

### 回调函数

```c
void EventProc(XS_ServerObject objServer, XS_HostObject objHost,
               struct mg_connection* c, int ev, void* ev_data)
{
    if ( ev == MG_EV_ACCEPT ) {
        printf("New connection from %M\n", mg_print_ip, &c->rem);
    } else if ( ev == MG_EV_READ ) {
        // 读取数据
        printf("Received %lu bytes\n", c->recv.len);
        
        // 处理数据
        // ...
        
        // 发送响应
        mg_send(c, "ACK", 3);
        
        // 清空接收缓冲区
        c->recv.len = 0;
    } else if ( ev == MG_EV_CLOSE ) {
        printf("Connection closed\n");
    }
}
```

### 最佳实践

1. **必须实现 EventProc** - TCP 服务必须提供 `EventProc` 回调
2. **粘包处理** - 自行处理 TCP 粘包/分包问题
3. **缓冲区管理** - 处理完数据后清空 `c->recv.len`
4. **超时设置** - 可设置 `c->pfn_data` 保存连接状态

### 常用事件

| 事件 | 说明 |
|------|------|
| `MG_EV_ACCEPT` | 新连接建立 |
| `MG_EV_READ` | 收到数据 |
| `MG_EV_WRITE` | 数据已发送 |
| `MG_EV_CLOSE` | 连接关闭 |
| `MG_EV_ERROR` | 发生错误 |

## UDP 服务

UDP 服务适用于低延迟、无连接的通信场景。

### 配置示例

```json
{
    "enabled": true,
    "class": "udp",
    "name": "UDP Server",
    "addr": "udp://0.0.0.0:5001",
    "host_default": {
        "enabled": true,
        "path": "udp",
        "devlang": "c",
        "devfile": "udp/main.c"
    },
    "hosts": []
}
```

### 回调函数

```c
void EventProc(XS_ServerObject objServer, XS_HostObject objHost,
               struct mg_connection* c, int ev, void* ev_data)
{
    if ( ev == MG_EV_READ ) {
        // 收到 UDP 数据包
        printf("Received from %M: %.*s\n", 
               mg_print_ip, &c->rem, 
               (int)c->recv.len, c->recv.buf);
        
        // 发送响应
        mg_send(c, "PONG", 4);
        
        // 清空缓冲区
        c->recv.len = 0;
    }
}
```

### 最佳实践

1. **无连接** - UDP 是无连接协议，每个包独立处理
2. **包大小** - 单个 UDP 包不应超过 MTU（通常 1500 字节）
3. **可靠性** - UDP 不保证送达，如需可靠传输需自行实现确认机制
4. **广播** - 可使用广播地址实现局域网广播

## Custom 服务

Custom 服务用于事件驱动的自定义服务，由脚本完全控制行为。

### 配置示例

```json
{
    "enabled": true,
    "class": "custom",
    "name": "Custom Service",
    "host_default": {
        "enabled": true,
        "path": "custom",
        "devlang": "c",
        "devfile": "custom/main.c"
    },
    "hosts": []
}
```

### 回调函数

```c
// 服务启动时调用
void ServiceStart(XS_ServerObject objServer, XS_HostObject objHost)
{
    printf("Custom service started\n");
    
    // 可以在这里创建自定义监听器
    // mg_http_listen(&mgr, "http://0.0.0.0:8888", my_handler, NULL);
}

// 服务停止时调用
void ServiceUnit(XS_ServerObject objServer, XS_HostObject objHost)
{
    printf("Custom service stopped\n");
}
```

### 最佳实践

1. **灵活控制** - 完全由脚本控制服务行为
2. **多监听器** - 可在 `ServiceStart` 中创建多个监听器
3. **定时任务** - 可使用 `mg_timer_add` 添加定时器
4. **资源清理** - 在 `ServiceUnit` 中释放所有资源

## Thread 服务

Thread 服务在独立线程中运行，适用于后台任务。

### 配置示例

```json
{
    "enabled": true,
    "class": "thread",
    "name": "Background Task",
    "host_default": {
        "enabled": true,
        "path": "task",
        "devlang": "c",
        "devfile": "task/main.c"
    },
    "hosts": []
}
```

### 回调函数

```c
// 线程入口
void ServiceStart(XS_ServerObject objServer, XS_HostObject objHost)
{
    printf("Thread started\n");
    
    while ( 1 ) {
        // 执行后台任务
        process_task();
        
        // 休眠一段时间
        sleep(1);
    }
}

void ServiceUnit(XS_ServerObject objServer, XS_HostObject objHost)
{
    printf("Thread stopping\n");
    // 设置退出标志
}
```

### 最佳实践

1. **独立线程** - `ServiceStart` 在独立线程中运行
2. **循环任务** - 适合需要持续运行的后台任务
3. **线程安全** - 访问共享资源时注意线程安全
4. **优雅退出** - 使用标志位控制线程退出

## 通用最佳实践

### 1. 错误处理

```c
int EventProc(...)
{
    // 使用 try-catch 风格的错误处理
    if ( some_error ) {
        MG_ERROR(("Error occurred: %s", error_msg));
        return 0;
    }
    // ...
}
```

### 2. 日志记录

```c
// 使用 Mongoose 的日志宏
MG_INFO(("Info message"));
MG_DEBUG(("Debug message"));
MG_ERROR(("Error message"));
```

### 3. 连接管理

```c
// 存储连接私有数据
c->fn_data = my_data;

// 设置连接超时
c->is_draining = 1;  // 发送完数据后关闭
```

### 4. 内存管理

```c
// 使用 XRT 内存函数
char* buf = xrtMalloc(size);
// ...
xrtFree(buf);

// 字符串复制
char* str = xrtCopyStr(src, len);
```

### 5. 热加载

```c
// 修改脚本后无需重启，调用热加载即可
int ret = xsReloadHost(objServer, objHost);
```
