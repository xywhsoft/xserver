# XServer 服务类型指南

XServer 当前支持 6 种服务类型，本文档介绍每种服务的特点、使用方式和最佳实践。以下 JSON 配置示例均为完整配置文件，统一使用根对象 + `services` 数组格式。

其中：

- HTTP / WebSocket 属于 HostAware 服务，脚本挂在 `host_default` 或 `hosts` 下
- XTP / TCP / UDP / Custom 属于 ServiceAware 服务，脚本挂在服务级 `path / devlang / devfile` 下

---

## 服务类型概览

| 服务类型 | class 值 | 协议 | TLS 支持 | 适用场景 |
|----------|----------|------|----------|----------|
| HTTP | `http` | HTTP/1.1 | HTTPS | Web 服务、REST API |
| WebSocket | `ws` | WebSocket | WSS | 实时通信、长连接 |
| XTP | `xtp` | XTP（自定义） | XTPS | 高性能二进制通信 |
| TCP | `tcp` | 原始 TCP | - | 自定义协议开发 |
| UDP | `udp` | UDP | - | 低延迟通信、广播 |
| Custom | `custom` | 自定义 | - | 事件驱动的自定义服务 |

---

## HTTP 服务

HTTP 服务是最常用的 Web 服务类型，支持静态文件服务和动态请求处理。

### 配置示例

```json
{
	"services": [
		{
			"enabled": true,
			"class": "http",
			"name": "Web Server",
			"ip": "0.0.0.0",
			"port": 80,
			"tls": true,
			"ip_tls": "0.0.0.0",
			"port_tls": 443,
			"host_default": {
				"enabled": true,
				"path": "wwwroot",
				"tls_cert": "tls/cert.pem",
				"tls_key": "tls/key.pem",
				"devlang": "c",
				"devfile": "script/main.c"
			},
			"hosts": []
		}
	]
}
```

### 回调函数

```c
bool RequestProc(XS_ServerObject objServer, XS_HostObject objHost, XS_RequestObject objReq, XS_ResponseObject objResp)
{
	const char* sPath = xsReqPath(objReq);

	if ( strcmp(sPath, "/index.html") == 0 ) {
		return false;
	}
	if ( strcmp(sPath, "/api/hello") == 0 ) {
		xsHttpHeader(objResp, "X-XS-Mode", "demo");
		return xsHttpJson(objResp, 200, "OK", "{\"result\":true,\"message\":\"hello\"}") != 0;
	}
	if ( strcmp(sPath, "/api/not-found") == 0 ) {
		return Ret404(objServer, objHost, objReq, objResp, "api route not found", NULL) != 0;
	}

	return false;
}
```

### 常用回调

| 回调 | 说明 |
|------|------|
| `ServiceInit` / `ServiceStart` / `ServiceStop` / `ServiceUnit` | Host 脚本生命周期 |
| `RequestProc` | 处理 HTTP 请求，返回 `false` 时继续走静态文件或默认错误页 |
| `MessageProc` | 接收总线消息 |

### 常用 API

| API | 说明 |
|-----|------|
| `xsReqMethod` / `xsReqPath` / `xsReqQuery` / `xsReqBody` | 读取请求信息 |
| `xsHttpStatus` / `xsHttpHeader` / `xsHttpText` / `xsHttpJson` / `xsHttpBody` | 构造响应 |
| `Ret403` / `Ret404` / `Ret500` / `RetError` | 走统一错误页返回，支持传入 `xvalue` 模板数据 |

### 最佳实践

1. **虚拟主机** - 使用 `hosts` 数组配置多个域名，每个域名可以有独立证书、脚本和错误页
2. **静态回退** - `RequestProc` 返回 `false` 时，可继续让静态文件或默认页处理请求
3. **统一错误页** - 优先使用 `Ret403/Ret404/Ret500/RetError`，不要手写分散的错误 HTML
4. **模板错误页** - `404页面`、`403页面`、`500页面`、`自定义错误页面` 指向 `.xtl` 时可注入模板变量

## WebSocket 服务

WebSocket 提供全双工通信，适用于实时应用。

### 配置示例

```json
{
	"services": [
		{
			"enabled": true,
			"class": "ws",
			"name": "WebSocket Server",
			"ip": "0.0.0.0",
			"port": 8080,
			"tls": true,
			"ip_tls": "0.0.0.0",
			"port_tls": 8443,
			"host_default": {
				"enabled": true,
				"path": "ws",
				"tls_cert": "tls/cert.pem",
				"tls_key": "tls/key.pem",
				"devlang": "c",
				"devfile": "ws/main.c"
			},
			"hosts": []
		}
	]
}
```

### 回调函数

```c
void WsOpenProc(XS_ServerObject objServer, XS_HostObject objHost, void* pConn)
{
	char sText[256];

	snprintf(
		sText,
		sizeof(sText),
		"ws open server=%s host=%s protocol=%s",
		xsServerName(objServer),
		xsHostName(objHost),
		xsWsProtocol(pConn)
	);
	xsLog(sText);
}

bool WsTextProc(XS_ServerObject objServer, XS_HostObject objHost, void* pConn, const char* pData, size_t iLen)
{
	(void)objServer;
	(void)objHost;

	if ( iLen == 4 && memcmp(pData, "ping", 4) == 0 ) {
		return xsWsSendText(pConn, "pong", 4) != 0;
	}

	return xsWsSendText(pConn, pData ? pData : "", iLen) != 0;
}

void WsCloseProc(XS_ServerObject objServer, XS_HostObject objHost, void* pConn, int iReason)
{
	char sText[256];
	(void)pConn;

	snprintf(
		sText,
		sizeof(sText),
		"ws close server=%s host=%s reason=%d",
		xsServerName(objServer),
		xsHostName(objHost),
		iReason
	);
	xsLog(sText);
}
```

### 常用回调

| 回调 | 说明 |
|------|------|
| `WsOpenProc` | WebSocket 握手完成 |
| `WsTextProc` | 收到文本帧，返回 `false` 时默认回显文本 |
| `WsBinaryProc` | 收到二进制帧，返回 `false` 时默认回显二进制 |
| `WsPingProc` / `WsPongProc` | 收到 ping / pong 控制帧 |
| `WsCloseProc` | 连接关闭 |
| `MessageProc` | 接收总线消息 |

### 常用 API

| API | 说明 |
|-----|------|
| `xsWsProtocol` | 获取协商后的子协议 |
| `xsWsSendText` / `xsWsSendBinary` | 发送文本或二进制帧 |
| `xsWsPing` | 发送 ping |
| `xsWsClose` | 主动关闭连接 |

### 最佳实践

1. **显式处理帧类型** - 文本和二进制分别放在 `WsTextProc`、`WsBinaryProc` 中处理
2. **利用默认回显** - 调试阶段可返回 `false` 使用内置回显，正式逻辑建议明确返回自己的数据
3. **心跳检测** - 客户端或服务端可定期发送 `ping`，在 `WsPingProc` / `WsPongProc` 中记录状态
4. **子协议分流** - 可用 `xsWsProtocol` 对不同业务协议做分支

## XTP 服务

XTP 是 XServer 自定义的轻量级二进制协议，适用于高性能场景。

### 协议格式

```
+------------------+-------------------+-------+---------+------+
| Header (16B)     | ParamInfo (4B*n)  | Cmd   | Params  | Body |
+------------------+-------------------+-------+---------+------+
```

**Header 结构（16 字节）：**

- `HeadInfo[4]` - 包头标识 `"xtp\1"`
- `PackSize` - 包总长度
- `CmdSize` - 命令长度
- `ParamCount` - 参数数量
- `BodySize` - Body 长度

### 配置示例

```json
{
	"services": [
		{
			"enabled": true,
			"class": "xtp",
			"name": "XTP Server",
			"ip": "0.0.0.0",
			"port": 9000,
			"tls": true,
			"ip_tls": "0.0.0.0",
			"port_tls": 9443,
			"path": "xtp",
			"devlang": "c",
			"devfile": "xtp/main.c"
		}
	]
}
```

### 回调函数

```c
bool EventXtpProc(XS_ServerObject objServer, void* pStream, void* pMsg)
{
	XTP_MessageObject objMsg = (XTP_MessageObject)pMsg;
	const char* sTag;
	char sBody[256];
	int iWrite;

	if ( !xsXtpCmdIs(objMsg, "demo.ping") ) {
		return false;
	}
	if ( !xsXtpHasParam(objMsg, "tag") ) {
		return xsXtpReplyMissingParam(pStream, objMsg, "tag") != 0;
	}

	sTag = xsXtpParamText(objMsg, "tag", "");
	iWrite = snprintf(
		sBody,
		sizeof(sBody),
		"xtp demo\nserver=%s\ntag=%s\n",
		xsServerName(objServer),
		sTag
	);
	if ( iWrite < 0 ) {
		return xsXtpReplyErrorText(pStream, objMsg, 500, "xtp.error", "format failed") != 0;
	}
	if ( !xsXtpNeedReply(objMsg) ) {
		return true;
	}

	return xsXtpReplyOKText(pStream, objMsg, "xtp.reply", sBody) != 0;
}
```

### 常用回调

| 回调 | 说明 |
|------|------|
| `ServiceInit` / `ServiceStart` / `ServiceStop` / `ServiceUnit` | 服务脚本生命周期 |
| `EventOpenProc` | 底层流连接建立 |
| `EventXtpProc` | 收到已解析的 XTP 消息，返回 `false` 时会走默认 `unhandled` 响应 |
| `EventCloseProc` | 底层流连接关闭 |

### 常用 API

| API | 说明 |
|-----|------|
| `xsXtpCmdIs` / `xsXtpCmd` / `xsXtpCmdLen` | 获取和匹配命令 |
| `xsXtpHasParam` / `xsXtpParamText` / `xsXtpParamInt` / `xsXtpParamBool` | 读取参数 |
| `xsXtpBody` / `xsXtpBodyLen` / `xsXtpBodyDup` | 读取 Body |
| `xsXtpNeedReply` / `xsXtpIsRequest` / `xsXtpIsResponse` | 判断消息类型和是否需要应答 |
| `xsXtpReplyOKText` / `xsXtpReplyJson` / `xsXtpReplyErrorText` | 返回业务响应 |
| `xsXtpReplyMissingParam` / `xsXtpReplyUnsupportedCmd` | 返回标准错误 |

### 最佳实践

1. **命令路由** - 优先用 `xsXtpCmdIs` 做命令分发，不要手工解析原始字节流
2. **参数校验** - 缺少必要参数时直接返回 `xsXtpReplyMissingParam`
3. **按需应答** - 先判断 `xsXtpNeedReply(objMsg)`，避免对无需回应的消息重复发送响应
4. **分层返回** - 正常业务用 `xsXtpReplyOKText` / `xsXtpReplyJson`，异常用 `xsXtpReplyErrorText`

## TCP 服务

原始 TCP 服务，适用于自定义协议开发。

### 配置示例

```json
{
	"services": [
		{
			"enabled": true,
			"class": "tcp",
			"name": "TCP Server",
			"ip": "0.0.0.0",
			"port": 5000,
			"path": "tcp",
			"devlang": "c",
			"devfile": "tcp/main.c"
		}
	]
}
```

### 回调函数

```c
void EventOpenProc(XS_ServerObject objServer, void* pStream)
{
	char sText[256];
	(void)pStream;

	snprintf(
		sText,
		sizeof(sText),
		"tcp open server=%s",
		xsServerName(objServer)
	);
	xsLog(sText);
}

bool EventDataProc(XS_ServerObject objServer, void* pStream, const void* pData, size_t iLen)
{
	char sBuf[256];
	int iWrite;

	iWrite = snprintf(
		sBuf,
		sizeof(sBuf),
		"tcp demo\nserver=%s\nbytes=%u\ndata=%.*s\n",
		xsServerName(objServer),
		(unsigned)iLen,
		(int)iLen,
		pData ? (const char*)pData : ""
	);
	if ( iWrite < 0 ) {
		return false;
	}

	return xsStreamSend(pStream, sBuf, strlen(sBuf)) != 0;
}

void EventCloseProc(XS_ServerObject objServer, void* pStream, int iReason)
{
	char sText[256];
	(void)pStream;

	snprintf(
		sText,
		sizeof(sText),
		"tcp close server=%s reason=%d",
		xsServerName(objServer),
		iReason
	);
	xsLog(sText);
}
```

### 常用回调

| 回调 | 说明 |
|------|------|
| `ServiceInit` / `ServiceStart` / `ServiceStop` / `ServiceUnit` | 服务脚本生命周期 |
| `EventOpenProc` | 新流连接建立 |
| `EventDataProc` | 收到数据，返回 `false` 时会走默认回显 |
| `EventCloseProc` | 连接关闭 |

### 常用 API

| API | 说明 |
|-----|------|
| `xsStreamSend` | 向当前流发送数据 |
| `xsStreamClose` | 主动关闭流 |

### 最佳实践

1. **自行做分包** - TCP 只有字节流，没有消息边界，需要业务层自行处理粘包与拆包
2. **显式返回 handled** - 已处理完数据时返回 `true`，需要内置回显时才返回 `false`
3. **连接状态自管** - 如需会话状态，请在脚本侧维护自己的连接上下文
4. **边界校验** - 先做长度和协议头校验，再进入业务解析

## UDP 服务

UDP 服务适用于低延迟、无连接的通信场景。

### 配置示例

```json
{
	"services": [
		{
			"enabled": true,
			"class": "udp",
			"name": "UDP Server",
			"ip": "0.0.0.0",
			"port": 5001,
			"path": "udp",
			"devlang": "c",
			"devfile": "udp/main.c"
		}
	]
}
```

### 回调函数

```c
bool EventDgramProc(XS_ServerObject objServer, void* pSock, const void* pFromAddr, const void* pData, size_t iLen)
{
	char sBuf[256];
	const char* sFrom;
	int iWrite;

	sFrom = xsAddrText(pFromAddr);
	iWrite = snprintf(
		sBuf,
		sizeof(sBuf),
		"udp demo\nserver=%s\nfrom=%s\nbytes=%u\ndata=%.*s\n",
		xsServerName(objServer),
		sFrom ? sFrom : "",
		(unsigned)iLen,
		(int)iLen,
		pData ? (const char*)pData : ""
	);
	if ( iWrite < 0 ) {
		return false;
	}

	return xsDgramReply(pSock, pFromAddr, sBuf, strlen(sBuf)) != 0;
}
```

### 常用回调

| 回调 | 说明 |
|------|------|
| `ServiceInit` / `ServiceStart` / `ServiceStop` / `ServiceUnit` | 服务脚本生命周期 |
| `EventDgramProc` | 收到 UDP 数据报，返回 `false` 时会走默认原样回包 |

### 常用 API

| API | 说明 |
|-----|------|
| `xsAddrText` | 将来源地址转成文本 |
| `xsDgramReply` | 向当前来源地址回复 |
| `xsDgramSendTo` | 向任意地址发送数据报 |

### 最佳实践

1. **单包独立处理** - UDP 不保证顺序和送达，每个包都应独立校验
2. **控制报文大小** - 业务数据尽量控制在单个 MTU 内
3. **慎用默认回包** - 调试可返回 `false`，正式逻辑建议显式调用 `xsDgramReply`
4. **广播与多播** - 需要主动投递时使用 `xsDgramSendTo`

4. **先定义协议边界** - 建议先约定帧头、长度、校验，再写业务逻辑

## 通用最佳实践

### 1. 错误处理

```c
if ( strcmp(xsReqPath(objReq), "/forbidden") == 0 ) {
	return Ret403(objServer, objHost, objReq, objResp, "permission denied", NULL) != 0;
}
```

### 2. 日志记录

```c
char sText[256];

snprintf(
	sText,
	sizeof(sText),
	"server=%s class=%d",
	xsServerName(objServer),
	xsServerClass(objServer)
);
xsLog(sText);
```

### 3. 优先使用脚本 API

不要直接依赖底层连接结构体字段，优先使用已导出的脚本 API，例如：

- HTTP 使用 `xsReqPath`、`xsHttpJson`、`Ret404`
- WebSocket 使用 `xsWsSendText`、`xsWsClose`
- TCP / Custom 使用 `xsStreamSend`、`xsStreamClose`
- UDP 使用 `xsDgramReply`、`xsAddrText`
- XTP 使用 `xsXtpCmdIs`、`xsXtpReplyOKText`

### 4. 内存管理

```c
char* sText = xrtCopyStr("hello", 0);

if ( sText ) {
	xrtFree(sText);
}
```

### 5. 热加载

```c
int iRet = xsReloadCurrentHost(objServer, objHost, 1);
```

`xsReloadCurrentHost` / `xsReloadHostByName` 主要用于 HTTP / WebSocket 这类 HostAware 脚本热加载。
