xsdbg builtin app

仅保留诊断能力的调试入口

这个页面只服务于协议调试、运行状态查看、reload/check 诊断与错误排查。 production `xs` 不再内置固定 `__xs/*`；如果业务需要网页端控制 Bus、重载或其他上层操作，应由应用层自己暴露路由并调用运行时 API。

内置 Bus 宿主管理、dashboard 总览和在线治理入口已经从主线清退。`xsdbg` 当前内置页不再预设这些 URI，也不再承载应用层功能。

边界说明

  • production `xs` 不再内置固定 `__xs/*`。
  • `Bus / reload / check_config` 仍然保留为运行时 API，但不再对应预设网页端 URI。
  • xsdbg 只保留诊断入口，不再内置 Bus 宿主管理、dashboard 总览或应用级治理页。
  • 如果要做业务控制台，请在应用层自己暴露路由，并调用 `xsData* / xsMsg* / xsReload*` 等 API。
