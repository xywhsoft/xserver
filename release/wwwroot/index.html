能力入口

这些页面和接口都已经接到当前 Host 的真实脚本实现。

图表页面
调用 `/chart/get`，验证脚本生成图表数据。
模板页面
调用 xrt 模板能力，验证模板读取、解析与渲染。
JSON 状态
查看脚本宿主暴露的 server/host/app_path 等状态。
宿主调试状态
查看当前 server、default host、script_loaded 等摘要。
宿主状态 JSON
直接读取结构化状态，便于脚本和外部工具消费。
健康检查 JSON
汇总宿主、reload、bus 的轻量健康摘要。
健康检查文本
返回简洁文本和明确的 200/503 状态码，适合探针。
HTTP 指标 JSON
查看当前进程内 HTTP 请求总量与 2xx/3xx/4xx/5xx 分布。
清空 HTTP 指标
将 HTTP 计数归零，便于压测窗口或故障复盘重新采样。
WS 指标 JSON
查看当前进程内 WebSocket 连接、消息、ping/pong 与错误统计。
清空 WS 指标
将 WebSocket 计数归零，便于压测窗口或故障复盘重新采样。
总览文本
以纯文本输出 status、health、reload、bus 的总览摘要。
总览 JSON
汇总 status、health、reload、bus 的结构化总览。
配置校验文本
在线校验当前配置文件，不触发热加载。
配置校验 JSON
结构化返回配置校验结果、配置路径和服务数量。
热重载 JSON
结构化触发脚本热重载，便于页面与工具直接消费。
Bus 宿主管理状态
直接查看宿主层 bus 注册表与队列状态，不经过业务脚本路由。
WebSocket 测试页
联调 `xs_ws.json` 对应的 WebSocket demo，验证连接、发送和回显。
WSS 测试页
页面内一键切到 `wss://127.0.0.1:8444/`，验证 TLS WebSocket 与子协议协商。
